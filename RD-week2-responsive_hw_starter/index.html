Basic Media Queries

In this assignment you will add two media queries to the CSS file.

  • The first media query triggers at 772px and changes the divs to 45% of the viewport width. Images have a maximum height of 30% of the viewport height.
  • The second media query triggers at 998px and changes the divs to 30% of the viewport width.
